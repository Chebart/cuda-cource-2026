Как пустой столбец убирает конфликт банков

Читаем первый столбец тайла (куска матрицы) в shared memory. Нажми на номер строки 10. Затем переключи ширину с 32 на 32 + 1 и посмотри, сколько банков участвует в чтении. Числа те же, а при ширине 33 у каждого потока свой банк.

Нажимай на номера строк: 6 — запись, 8 — барьер, 10 — чтение. Чтобы поменять ширину, нажми на второе число в объявлении tile. На телефоне после переключения прокрути ниже, до блока «Читаем первый столбец», и посмотри, сколько банков участвует в чтении. Здесь считаем числа в ядре, а в полном примере берём их из input. Для запуска demo<<<1, 32>>>(out) заранее выдели на GPU массив out на 32 float.

Шаг 01 / 03

Записываем одну строку

Смотрим на строку с индексом 2. Соседние потоки пишут в соседние ячейки — в разные банки.

Без конфликта: 32 из 32 банковПо одному слову на банк
Потоки warpвыбери поток · стрелки с клавиатуры
Банки shared memoryвыделен банк выбранного потока
tile[2][2]индекс слова: 2 × 32 + 2 = 66значение: 2 × 32 + 2 = 66банк: 66 % 32 = 2

В shared memory здесь 32 банка. Разные банки могут работать одновременно. Чтобы узнать номер банка, считаем 4-байтные слова от начала tile и берём остаток от деления индекса слова на 32. Число, которое лежит в ячейке, для этого не нужно.

Зачем нужен пустой столбец? Добавили по ячейке в конце каждой строки. Это padding: мы эти ячейки не заполняем и не читаем. Теперь между началами строк 33 слова вместо 32, а числа те же. За это тратим ещё 128 байт shared memory на блок.
