CUDA-массивы: читаем через texture, пишем через surface

В первой программе просим GPU получить число между соседними пикселями. Во второй записываем четыре числа в ячейки нового массива. Результат первой программы для второй не нужен.

Texture: читаем между четырьмя пикселями

Как подготовить массив к чтению

Готовим пиксели. У нас по одному float на пиксель. По этому формату выделяем CUDA-массив 2×2. Через cudaMemcpy2DToArray копируем из pixels две строки: сначала [0, 4], потом [8, 12].

Настраиваем чтение. В resource указываем, откуда читать, в description — как. В строке 35 включаем линейный фильтр. В строке 38 получаем texture — идентификатор, по которому ядро найдёт массив и настройки. Пиксели остаются в массиве.

Получаем число между пикселями. В строке 12 передаём texture и точку (1, 1) в tex2D<float>. Получаем число 6 типа float и пишем его в output[0].

Запуск: получаем 6 между пикселями

nvcc -std=c++17 -O3 -arch=sm_75 08_texture.cu -o 08_texture
./08_texture

Вывод:

texture = 6.0, expected = 6.0
PASS

Сравни texture с expected. Первое число вернул tex2D, второе посчитали по схеме: в центре берём по четверти от значения каждого пикселя. Оба числа равны 6 — получаем PASS.

Листинг 09 / Surface

Surface: заполняем CUDA-массив четырьмя потоками

Хотим записать в CUDA-массив две строки: [6, 7] и [8, 9]. К его ячейкам нельзя обратиться как к обычному массиву через float*. Поэтому создаём surface и передаём его ядру.

Как поток находит свою ячейку

Запускаем один блок dim3(2, 2): два потока по X и два по Y. Каждый берёт свой столбец из threadIdx.x, а строку — из threadIdx.y. Число для своей ячейки считает так: 6 + y * 2 + x.

Как подключаем массив и читаем результат

Подключаем массив. Выделяем массив 2×2 по одному float на ячейку и разрешаем доступ через surface. В resource указываем этот массив. В строке 30 получаем идентификатор surface, который передадим ядру.

Пишем число. В строке 16 surf2Dwrite находит массив по surface, а ячейку — по X в байтах и Y в строках. Число пишем в массив, не в сам объект surface.

Проверяем результат. В строке 39 копируем обе строки на CPU через cudaMemcpy2DFromArray. Посмотри на два rowBytes: первый — шаг до следующей строки в host, второй — сколько байт копируем из каждой строки. Здесь оба по 8 байт: по два float в строке, и строки лежат вплотную.

Запуск: проверяем все четыре ячейки

nvcc -std=c++17 -O3 -arch=sm_75 09_surface.cu -o 09_surface
./09_surface

Вывод:

surface: 6 7; 8 9
PASS

Сверь с матрицей на схеме: до точки с запятой — верхняя строка, после — нижняя. Сверяем все четыре ячейки на CPU после копирования. PASS — каждое число на своём месте.
