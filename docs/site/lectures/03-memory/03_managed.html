Один массив для CPU и GPU

Хотим прибавить 1 к каждому числу в [2, 4, 6, 8] на GPU и прочитать результат на CPU. Для этого будем работать с одним массивом, а не с двумя буферами.

CPU заполняет, GPU меняет, CPU читает

Выделяем массив через cudaMallocManaged. И CPU, и GPU обращаются к массиву по одному указателю. Это управляемая память (Unified Memory).

Скачать .cu

Как передать ядру тот же массив

Строка 19: выделяем общий массив. Затем заполняем его с CPU.

Строка 27: передаём ядру тот же values. Каждый из четырёх потоков прибавляет 1 к своему числу.

Строка 29: ждём, пока GPU закончит менять числа. Только потом читаем values с CPU.

Запуск: массив до и после ядра

Нужны CUDA Toolkit и GPU с поддержкой управляемой памяти.

nvcc -std=c++17 -O3 -arch=sm_75 03_managed.cu -o managed
./managed

Вывод:

before: [2, 4, 6, 8]
after: [3, 5, 7, 9]

Сравни before и after: в каждой ячейке стало на 1 больше. Оба раза CPU читает один и тот же массив через values: до запуска ядра и после ожидания.
